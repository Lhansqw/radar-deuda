# Demo tienda (Python)

Repositorio de ejemplo con deuda técnica intencionada para probar los analizadores de Python
de Radar de Deuda Técnica: una función compleja (`procesar_pedido`), un ciclo de importaciones
(`pedidos` ↔ `clientes`), un bloque duplicado (`clientes` y `facturas`), marcadores FIXME/TODO
y ninguna prueba.

```powershell
npm run analyze -- examples\demo-python
```
